## Welcome to the usermods page. Thanks everyone for building, modding and upgrading trinity, I love to see the different variants pop up!
These projects are not my work so if you have questions you should contact the maker, feel free to do so in the trinity channel though!


### Prooda:
Made for the same configuration as trinity except with ["chube compact"](https://www.lukeslabonline.com/products/chube-compact), this version of trinity is basically its own cad now because everything was changed. Ask prooda if you have questions about this version.
supports mgn9 with 6mm belts, and mgn12 with 6 & 9mm belts. NOTE that the ducts are wider than the original trinity ducts


### Zerodegree79
Added support for the ["magneto filament cutter"](https://biqu.equipment/products/bigtreetech-magneto-cutter-auto-loading-magnetic-filament-cutter-for-vzbot-3d-printer-toolhead-high-precision-upgrade-accessories) Designed to be used with the [A4T - WWBMG - Dual sensor Sherpa-Mini spacing](https://github.com/Armchair-Heavy-Industries/A4T/blob/main/CAD/WW-BMG%20for%20A4T/A4T%20-%20WWBMG%20-%20Main_Body%20%5BSherpa-Mini%20spacing%5D%20Dual%20Sensor.step)
- The chube compact version is almost untouched from prooda's design
- the volcano UHF and t-volcano(NOT ACE) versions include a hotend fan duct based on tas' work with a4t, include a thermistor for the heatsink, and uses square nuts to mount the extruder.
Notes:
The ducts on the volcano versions are not compatible with the klicky mount because the third mounting point is removed, the ducts from prooda's version or the original trinity files are compatible though


### cpp0xc0ffeeee:
Added support for the ["mellow heatercore"](https://3dmellow.com/products/mellow-heatcore-4-uhf-alps-hotend-smart-leveling-nozzle-probe-for-voron-blv-vzbot-hevort-diy-3d-printer-high-flow-and-high-speed) hotend and monolith belt clips by Tas
