## Welcome to the usermods page. Thanks everyone for building, modding and upgrading trinity, I love to see the different variants pop up!
These projects are not my work so if you have questions you should contact the maker, feel free to do so in the trinity channel though!


### Prooda:
Made for the same configuration as trinity except with ["chube compact"](https://www.lukeslabonline.com/products/chube-compact), this version of trinity is basically its own cad now because everything was changed. Ask prooda if you have questions about this version.
supports mgn9 with 6mm belts, and mgn12 with 6 & 9mm belts


### Zerodegree79
Added support for the ["magneto filament cutter"](https://biqu.equipment/products/bigtreetech-magneto-cutter-auto-loading-magnetic-filament-cutter-for-vzbot-3d-printer-toolhead-high-precision-upgrade-accessories) Should be used with the [A4T - WWBMG - Dual sensor Sherpa-Mini spacing](https://github.com/Armchair-Heavy-Industries/A4T/blob/main/CAD/WW-BMG%20for%20A4T/A4T%20-%20WWBMG%20-%20Main_Body%20%5BSherpa-Mini%20spacing%5D%20Dual%20Sensor.step)
Versions are available for the chube compact, dragon UHF, and dragon T-volcano (NOT ACE VOLCANO) hotends. They sadly do NOT support klicky probe due to the removal of the third probe mounting point.
The dragon hotend versions support a thermistor for the heatbrake as well.
